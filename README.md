# Extended and user-oriented Versioning Specification

![ExuoVer Logo](./assets/dark_x512.png)

"Extended and user-oriented Versioning" or "ExouVer" contain a set of rules and requirements for specifying how to assign and increment version numbers for games, mods, applications, etc.
You can find the latest version (Simplified Chinese) in [ExuoVer.md](./ExuoVer.md), or check the [specific categories](./docs) of this repository for different versions, if any.

## Chinese
“扩展并面向用户的版本”，简称“ExouVer”，包含一系列在为游戏、模组、应用等分配与增加版本号时的规则和要求。
你可以在 [ExuoVer.md](./ExuoVer.md) 找到最新版文档，或者在 [具体分类](./docs) 中寻找其他版本（如果有的话）。
